# Paguei Barato Ofertas — Site V1

Site estático preparado para GitHub Pages.

## Arquivos principais
- `index.html` — página inicial
- `styles.css` — visual responsivo
- `script.js` — produtos, busca e filtros
- `robots.txt` — rastreamento
- `sitemap.xml` — sitemap inicial
- `404.html` — página de erro
- `assets/logo.svg` — marca provisória da V1

## Próximas etapas
1. Subir todos os arquivos para a raiz do repositório `pagueibaratoofertas.github.io`.
2. Ativar GitHub Pages em **Configurações > Pages**.
3. Substituir os produtos de demonstração por ofertas reais.
4. Adicionar links de afiliado e Grupo VIP.
5. Conectar ao Google Search Console.
